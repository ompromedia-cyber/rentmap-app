# RentMap Telegram Mini App\n\nTelegram Mini App for finding nearby rental listings on a map.\n\n## Stack\n- Laravel 11 / PHP 8.2+\n- MySQL 8+\n- Telegram WebApp authentication\n- Leaflet + OpenStreetMap\n- Vanilla HTML/CSS/JavaScript\n\n## Current MVP\n\nThe repository now contains:\n- responsive Leaflet map\n- category filters\n- browser geolocation and nearby search\n- highlighted listing names and prices\n- Laravel REST API\n- MySQL migrations and spatial location field\n- Telegram WebApp `initData` signature verification\n- users, listings, photos and favorites models\n- listing creation endpoint\n- favorites endpoints\n\n## API\n\nPublic:\n- GET `/api/categories`\n- GET `/api/listings?lat=&lng=&radius=&category=`\n- GET `/api/listings/{id}`\n\nTelegram-authenticated:\n- POST `/api/telegram/auth`\n- POST `/api/listings`\n- POST `/api/listings/{id}/photos` (до 10 изображений, максимум 8 МБ каждое)\n- DELETE `/api/listing-photos/{photo}`\n- POST `/api/favorites/{listing}`\n- DELETE `/api/favorites/{listing}`\n\nFor authenticated requests, send the Telegram WebApp `initData` string in:\n\n```\nX-Telegram-Init-Data: <initData>\n```\n\nThe backend verifies the HMAC signature using `TELEGRAM_BOT_TOKEN` before creating/finding the local user.\n\n## Backend setup\n\nRequirements:\n- PHP 8.2+\n- Composer\n- MySQL 8+\n\nInstall dependencies:\n\n```bash\ncomposer install\n```\n\nCreate environment:\n\n```bash\ncp .env.example .env\nphp artisan key:generate\n```\n\nSet MySQL credentials and your Telegram bot token in `.env`:\n\n```env\nDB_DATABASE=rentmap\nDB_USERNAME=root\nDB_PASSWORD=your_password\n\nTELEGRAM_BOT_TOKEN=123456:ABCDEF...\n```\n\nCreate the public storage symlink:\n\n```bash\nphp artisan storage:link\n```\n\nRun migrations:\n\n```bash\nphp artisan migrate\n```\n\nStart locally:\n\n```bash\nphp artisan serve\n```\n\nThe API will be available under `/api`.\n\n## Frontend\n\nThe frontend is in `frontend/`.\n\nIt expects the Laravel API at `/api` on the same domain. If frontend and backend are hosted separately, define before loading `app.js`:\n\n```html\n<script>\n  window.RENTMAP_API_BASE = 'https://your-api.example.com/api';\n</script>\n```\n\nFor production Telegram Mini App hosting, serve the frontend over HTTPS and configure the BotFather Mini App URL to point to the frontend.\n\n## Database\n\nLaravel migrations are in `database/migrations/`.\n\nThe original SQL reference remains in `database/schema.sql`.\n\nThe `listings.location` column is a MySQL SRID 4326 POINT with a spatial index. Nearby searches use MySQL `ST_Distance_Sphere`.\n\n## Next development steps\n\n1. Add listing creation UI for landlords.\n2. Add photo upload and image storage.\n3.
